## 각 로드맵에 포함된 내용

각 로드맵에는 다음이 포함됩니다:

- **ASCII 아트 다이어그램** — 시각적 커리어 진행 경로
- **스킬 체크리스트** — 체크박스 기반 스킬 추적
- **학습 리소스** — 엄선된 도서, 강좌, 문서
- **프로젝트 아이디어** — 각 단계별 포트폴리오 가치가 있는 프로젝트
- **면접 준비** — 자주 나오는 질문과 팁
- **연봉 정보** — 레벨 및 지역별 보상 데이터
- **중국어 버전** — 각 파일 끝에 중국어 번역

## 빠른 시작

1. **나의 로드맵 찾기** — 커리어 목표에 맞는 역할을 선택하세요
2. **현재 레벨 평가** — 현재 어떤 단계에 있는지 파악하세요
3. **스킬 확인** — 체크박스를 사용해 진행 상황을 추적하세요
4. **프로젝트 구축** — 각 단계의 프로젝트를 완성하여 포트폴리오를 만드세요
5. **면접 준비** — 지원 전 면접 팁을 검토하세요

## 커리어 레벨

| 레벨 | 경력 | 설명 |
|-------|------------|-------------|
| **주니어** | 0-2년 | 기초 학습, 기본 기능 구현 |
| **미드** | 2-4년 | 독립적 업무, 팀 프로젝트 기여 |
| **시니어** | 4-7년 | 기능 리딩, 멘토링, 기술 의사결정 |
| **스태프** | 7-10년 | 크로스팀 영향력, 아키텍처, 기술 전략 |
| **프린시펄** | 10년+ | 조직 전체 영향력, 혁신, 산업 리더십 |
