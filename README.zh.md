## 每份路线图包含

- **ASCII 职业路径图** — 可视化的职业进阶路径
- **技能清单** — 带复选框的技能跟踪
- **学习资源** — 精选书籍、课程和文档
- **项目实战** — 每个阶段的项目作品集
- **面试准备** — 常见问题和技巧
- **薪资参考** — 按级别和地区的薪资数据
- **中文版本** — 每份文件末尾的中文翻译

## 快速开始

1. **找到你的路线图** — 选择与职业目标匹配的角色
2. **评估你的水平** — 确定你目前所处的阶段
3. **检查技能清单** — 使用复选框跟踪你的进度
4. **构建项目** — 完成每个阶段的项目来丰富你的作品集
5. **准备面试** — 申请前回顾面试技巧

## 职业级别

| 级别 | 经验 | 描述 |
|------|------|------|
| **初级 (Junior)** | 0-2 年 | 学习基础知识，构建基本功能 |
| **中级 (Mid)** | 2-4 年 | 独立工作，为团队项目做贡献 |
| **高级 (Senior)** | 4-7 年 | 主导功能开发，指导他人，技术决策 |
| **资深 (Staff)** | 7-10 年 | 跨团队影响，架构设计，技术战略 |
| **首席 (Principal)** | 10+ 年 | 组织级影响，创新，行业引领 |
