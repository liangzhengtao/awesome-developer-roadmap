## Was jede Routenmap enthält

Jede Routenmap umfasst:

- **ASCII-Art-Diagramm** — Visueller Karrierefortschritts-Pfad
- **Skills-Checkliste** — Checkbox-basiertes Skill-Tracking
- **Lernressourcen** — Kuratierte Bücher, Kurse und Dokumentation
- **Projektideen** — Portfolio-taugliche Projekte für jede Phase
- **Vorbereitung auf Vorstellungsgespräche** — Häufige Fragen und Tipps
- **Gehaltserwartungen** — Vergütungsdaten nach Level und Region
- **Chinesische Version** — Chinesische Übersetzung am Ende jeder Datei

---

## Schnellstart

1. **Finden Sie Ihre Routenmap** — Wählen Sie die Rolle, die zu Ihren Karrierezielen passt
2. **Bewerten Sie Ihr Level** — Bestimmen Sie, in welcher Phase Sie sich befinden
3. **Prüfen Sie die Skills** — Nutzen Sie die Checkboxes, um Ihren Fortschritt zu verfolgen
4. **Erstellen Sie Projekte** — Schließen Sie Projekte jeder Phase ab, um Ihr Portfolio aufzubauen
5. **Bereiten Sie sich vor** — Überprüfen Sie die Interview-Tipps vor der Bewerbung

## Karriere-Level

| Level | Erfahrung | Beschreibung |
|-------|------------|-------------|
| **Junior** | 0-2 Jahre | Grundlagen lernen, Basisfunktionen entwickeln |
| **Mid** | 2-4 Jahre | Selbstständige Arbeit, Beitrag zu Teamprojekten |
| **Senior** | 4-7 Jahre | Feature-Leitung, Mentoring, technische Entscheidungen |
| **Staff** | 7-10 Jahre | Teamübergreifende Wirkung, Architektur, technische Strategie |
| **Principal** | 10+ Jahre | Organisationsweite Wirkung, Innovation, Branchenführung |
