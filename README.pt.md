## O que há em cada roteiro

Cada roteiro inclui:

- **Diagrama ASCII Art** — Caminho visual de progressão na carreira
- **Checklist de Habilidades** — Rastreamento baseado em caixas de seleção
- **Recursos de Aprendizagem** — Livros, cursos e documentação curados
- **Ideias de Projetos** — Projetos dignos de portfólio para cada fase
- **Preparação para Entrevistas** — Perguntas comuns e dicas
- **Expectativas Salariais** — Dados de remuneração por nível e região
- **Versão em Chinês** — Tradução chinesa no final de cada arquivo

---

## Início Rápido

1. **Encontre seu roteiro** — Escolha o cargo que combina com seus objetivos de carreira
2. **Avalie seu nível** — Identifique em qual fase você está atualmente
3. **Verifique as habilidades** — Use as caixas de seleção para acompanhar seu progresso
4. **Construa projetos** — Complete projetos de cada fase para montar seu portfólio
5. **Prepare-se para entrevistas** — Revise as dicas de entrevista antes de se candidatar

## Níveis de Carreira

| Nível | Experiência | Descrição |
|-------|------------|-------------|
| **Júnior** | 0-2 anos | Aprendendo fundamentos, construindo funcionalidades básicas |
| **Pleno** | 2-4 anos | Trabalho independente, contribuindo em projetos de equipe |
| **Sênior** | 4-7 anos | Liderando funcionalidades, mentorando outros, decisões técnicas |
| **Staff** | 7-10 anos | Impacto entre equipes, arquitetura, estratégia técnica |
| **Principal** | 10+ anos | Impacto organizacional, inovação, liderança no setor |
