## What's Inside Each Roadmap

Each roadmap includes:

- **ASCII Art Diagram** — Visual career progression path
- **Skills Checklist** — Checkbox-based skill tracking
- **Learning Resources** — Curated books, courses, and documentation
- **Project Ideas** — Portfolio-worthy projects for each stage
- **Interview Preparation** — Common questions and tips
- **Salary Expectations** — Compensation data by level and region
- **Chinese Version** — Chinese translation at the end of each file

## Quick Start

1. **Find your roadmap** — Choose the role that matches your career goals
2. **Assess your level** — Identify which stage you're currently at
3. **Check the skills** — Use the checkboxes to track your progress
4. **Build projects** — Complete projects from each stage to build your portfolio
5. **Prepare for interviews** — Review the interview tips before applying

## Career Levels

| Level | Experience | Description |
|-------|------------|-------------|
| **Junior** | 0-2 years | Learning fundamentals, building basic features |
| **Mid** | 2-4 years | Independent work, contributing to team projects |
| **Senior** | 4-7 years | Leading features, mentoring others, technical decisions |
| **Staff** | 7-10 years | Cross-team impact, architecture, technical strategy |
| **Principal** | 10+ years | Organization-wide impact, innovation, industry leadership |
