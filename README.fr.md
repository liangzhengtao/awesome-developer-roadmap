## Contenu de chaque feuille de route

Chaque feuille de route inclut :

- **Diagramme ASCII de parcours** — Visualisation de l'évolution de carrière
- **Liste de compétences** — Suivi des compétences avec cases à cocher
- **Ressources d'apprentissage** — Livres, cours et documentation sélectionnés
- **Idées de projets** — Projets dignes d'un portfolio pour chaque étape
- **Préparation aux entretiens** — Questions fréquentes et conseils
- **Attentes salariales** — Données de rémunération par niveau et région
- **Version chinoise** — Traduction chinoise en fin de chaque fichier

---

## Démarrage rapide

1. **Trouvez votre feuille de route** — Choisissez le rôle qui correspond à vos objectifs de carrière
2. **Évaluez votre niveau** — Identifiez l'étape où vous en êtes actuellement
3. **Vérifiez les compétences** — Utilisez les cases à cocher pour suivre vos progrès
4. **Construisez des projets** — Complétez les projets de chaque étape pour enrichir votre portfolio
5. **Préparez les entretiens** — Révisez les conseils d'entretien avant de postuler

## Niveaux de carrière

| Niveau | Expérience | Description |
|-------|------------|-------------|
| **Junior** | 0-2 ans | Apprentissage des fondamentaux, construction de fonctionnalités de base |
| **Mid** | 2-4 ans | Travail autonome, contribution aux projets d'équipe |
| **Senior** | 4-7 ans | Pilotage de fonctionnalités, mentorat, décisions techniques |
| **Staff** | 7-10 ans | Impact inter-équipes, architecture, stratégie technique |
| **Principal** | 10+ ans | Impact à l'échelle de l'organisation, innovation, leadership sectoriel |
