## 各ロードマップの内容

各ロードマップには以下が含まれます：

- **ASCII キャリアパス図** — ビジュアルなキャリア進歩パス
- **スキルチェックリスト** — チェックボックス式スキルトラッキング
- **学習リソース** — 厳選された書籍、コース、ドキュメント
- **プロジェクトアイデア** — 各ステージにふさわしいポートフォリオプロジェクト
- **面接準備** — よくある質問とアドバイス
- **給与目安** — レベル・地域別の報酬データ
- **中国語版** — 各ファイル末尾の中国語翻訳

---

## クイックスタート

1. **ロードマップを見つける** — キャリア目標に合ったロールを選ぶ
2. **レベルを自己評価** — 現在のステージを把握する
3. **スキルを確認** — チェックボックスで進捗をトラッキング
4. **プロジェクトを構築** — 各ステージのプロジェクトを完成させてポートフォリオを充実させる
5. **面接準備** — 応募前に面接のアドバイスを確認する

## キャリアレベル

| レベル | 経験 | 説明 |
|-------|------------|-------------|
| **ジュニア** | 0-2年 | 基礎を学び、基本機能を構築 |
| **ミドル** | 2-4年 | 独立して作業し、チームプロジェクトに貢献 |
| **シニア** | 4-7年 | 機能を主導、メンタリング、技術的意思決定 |
| **スタッフ** | 7-10年 | チーム横断的な影響、アーキテクチャ、技術戦略 |
| **プリンシパル** | 10年以上 | 組織全体への影響、イノベーション、業界リーダーシップ |
