## Что внутри каждой дорожной карты

Каждая дорожная карта включает:

- **ASCII-диаграмму** — Наглядный путь карьерного роста
- **Чеклист навыков** — Отслеживание навыков с помощью чекбоксов
- **Учебные ресурсы** — Тщательно подобранные книги, курсы и документация
- **Идеи проектов** — Проекты для портфолио на каждом этапе
- **Подготовка к собеседованиям** — Частые вопросы и советы
- **Ожидания по зарплате** — Данные о компенсациях по уровням и регионам
- **Китайская версия** — Перевод на китайский в конце каждого файла

## Быстрый старт

1. **Найдите свою дорожную карта** — Выберите роль, соответствующую вашим карьерным целям
2. **Оцените свой уровень** — Определите, на каком этапе вы находитесь
3. **Проверьте навыки** — Используйте чекбоксы для отслеживания прогресса
4. **Создавайте проекты** — Выполняйте проекты каждого этапа для формирования портфолио
5. **Готовьтесь к собеседованиям** — Изучите советы перед подачей заявки

## Карьерные уровни

| Уровень | Опыт | Описание |
|-------|------------|-------------|
| **Джуниор** | 0-2 года | Изучение основ, создание базового функционала |
| **Миддл** | 2-4 года | Самостоятельная работа, вклад в командные проекты |
| **Сеньор** | 4-7 лет | Руководство функциями, наставничество, технические решения |
| **Стафф** | 7-10 лет | Кросс-командное влияние, архитектура, техническая стратегия |
| **Принципал** | 10+ лет | Влияние на уровне организации, инновации, лидерство в индустрии |
