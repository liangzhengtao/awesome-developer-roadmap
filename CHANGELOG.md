## Version History

### How to Update

When making changes to this project:

1. Add entries to the `[Unreleased]` section
2. When releasing a new version:
   - Move `[Unreleased]` items to a new version section
   - Update the version number
   - Add the release date
   - Create a git tag

### Version Numbering

- **Major** (X.0.0): Breaking changes, new roadmap structure
- **Minor** (0.X.0): New roadmaps, significant content additions
- **Patch** (0.0.X): Bug fixes, minor updates, typo corrections

## Contributing to the Changelog

When submitting a PR, please add your changes to the `[Unreleased]` section:

```markdown
## [Unreleased]

### Added
- New feature or content

### Changed
- Updates to existing content

### Fixed
- Bug fixes or corrections

### Removed
- Removed content
```

### Entry Format

- Start with a verb (Added, Changed, Fixed, Removed)
- Be specific about what changed
- Reference issue/PR numbers when applicable
- Group related changes together

Example:
```markdown
### Added
- Added salary data for European markets (#42)
- Added new learning resources for React (#38)

### Fixed
- Fixed broken links in Frontend Roadmap (#45)
- Updated salary data for 2024 (#43)
```
